# CSDN 广告投放自动化

把 CSDN 广告投放从分散在活动页、数据平台、后台和表格中的人工操作，整理成一套可由 AI 执行、运营确认、数据可追踪的本地工作台。

它面向需要反复创建 CSDN 广告活动、管理人群与物料、核对后台任务并持续查看投放数据的运营和协作团队。日常由 AI 操作项目脚本，运营负责确认产品事实、投放物料、计费价格和最终提交。

## 工作方式

项目把一次投放串成一条有确认节点、有执行记录、有数据回流的流程：

```text
活动链接
  → 产品与人群拆分
  → 文案与投放物料
  → 用户确认
  → 整活动 YAML
  → 后台建任务组、资源、客群和任务工单
  → 数据写入 SQLite
  → 看板查看与自动复盘
```

脚本本身默认 dry-run；正常建批在用户确认 YAML 后直接执行 `--submit`。dry-run 仅用于脚本刚改完或配置排查，不再作为每次建批前的固定步骤。

## 核心能力

- **活动策划**：整理产品事实、活动细则、人群分组、关键词和文案角度。
- **物料生成**：根据活动定义生成投放物料 HTML 和整活动 YAML。
- **后台执行**：核对并创建任务组、资源、客群、分发名单和任务工单，支持断点续跑与结果回读。
- **数据与复盘**：从后台取数写入 SQLite，通过本地看板查看指标，并生成待复盘队列和活动复盘。
- **人工确认**：登录、价格、物料和正式提交等关键环节保留人工决策。
- **运行边界**：脚本不带 `--submit` 时默认 dry-run；正常建批按确认后的 YAML 直接提交。本机登录态、运行数据和客户活动不会随部署结果对外传播。

## AI 一键部署

准备一台 Windows 10/11 或 macOS 电脑，并打开能够操作本机终端和浏览器的 AI 工具。把下面这段话发给 AI：

```text
帮我部署这个项目：https://github.com/Musea-HaiTang/ad-campaign-automation
请先克隆仓库，再严格按仓库根目录的“AI一键部署.md”执行。
```

AI 会检查现有环境、完成部署和测试，然后先提示下一步，等你准备好后再同时打开 CSDN 广告后台与数据平台。缺少 Python 或浏览器时，AI 必须先说明并征得同意后才能安装。看板只在后台运行，不会自动打开。

部署时，使用者只需要：

1. 告诉 AI 真实操作人名称。
2. 在 AI 打开的页面中完成 CSDN 广告后台和 `data.csdn.net` 登录。

完整执行顺序、成功标准和异常处理统一见 [AI 一键部署](AI一键部署.md)。技术命令见 [AI 部署说明](automation/docs/部署说明.md)。

## 第一次使用

部署并通过验收后，直接向 AI 提供一个活动链接：

```text
进行这个活动：<活动链接>
```

AI 会先查产品和活动事实、拆分人群并准备文案与物料；在运营确认之前，不会直接创建后台任务。日常任务、确认节点和数据查看方式见[运营使用说明](运营使用说明.md)。

## 项目结构

| 目录 | 作用 |
|---|---|
| `activities/` | 活动配置、物料和整活动 YAML；运行历史进入数据库 |
| `ad_output/` | 业务流程、文案规则、物料模板和 YAML 生成工具 |
| `automation/` | 执行脚本、数据库、取数、判定、巡检和自动复盘 |
| `web/` | 本地看板服务与前端页面 |
| `scripts/` | AI 部署、环境诊断和发布校验 |
| `automation/tests/` | 不打开真实浏览器的自动化测试 |
