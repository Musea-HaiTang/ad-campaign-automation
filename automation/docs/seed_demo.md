# 假数据种子（`seed_demo.py`）· 演示 / 上手用

**干什么**：按 `activities/_示例活动/` 的 YAML 造一个**假台账库**，让看板立刻有东西看——
不连后台、不登录、不动真实台账库。

```powershell
.venv\Scripts\python.exe automation/scripts/seed_demo.py
.venv\Scripts\python.exe web/app.py --db activities/_db/示例看板.db --port 8788
# 浏览器打开 http://127.0.0.1:8788
```

数据是**故意做成能展示全部界面状态**的：

| 桶 | 演示什么 |
|---|---|
| A | 首批 + 二批：**过门槛** → 弹窗是「胜出特写」；批次之间能看到两批；待复盘角标会出现 |
| B | 只跑过首批：**没到门槛** → 弹窗是「记分卡」；同时演示"每个桶有自己的当前批" |

**注意**

- 默认写 `activities/_db/示例看板.db`；**不允许**写真实库 `投放数据.db`（脚本会拒绝）。
- 想回到干净状态，重新跑一次即可（会先删掉那个假库再重建）。
- `activities/_示例活动/` 是下划线开头 → **不进看板活动下拉**，不会污染日常看板。
