# 等登录 · `wait_login.py`（只读）

> 登录态失效时，开个浏览器让你重新登录；**真的恢复了**才继续干活。两个站都走这一条命令（`--site`）。

## 为什么有它

CSDN 广告后台的登录态会**按模块**失效。2026-09-16 那天：

| 现象 | 结论 |
|---|---|
| 页面能打开、任务列表能查（`taskPageList` 正常） | 看起来"没掉线" |
| `/admin/export/*` 全部返回 `code=400600 无权限`，页面提示「无权访问，请重新登录」 | 实际是登录态失效 |

光看"页面能打开"判断不出来，猜来猜去浪费时间。这个脚本把判断变成事实：
**每 5 秒探一次接口权限，恢复了才算数**。

## 怎么跑

```powershell
.venv\Scripts\python.exe -u automation/scripts/wait_login.py                  # 默认 = 广告后台
.venv\Scripts\python.exe -u automation/scripts/wait_login.py --site databi     # 数据平台
... --minutes 20      # 最多等多少分钟（默认 15）
... --url <页面>       # 打开哪个页面等你登录（不给就按 --site 取默认）
```

## 两个站怎么判（`--site`）

| `--site` | 站 | 默认打开的页面 | 判定口径 |
|---|---|---|---|
| `admin`（默认） | CSDN **广告后台** `mp-admin.csdn.net` | 导出任务管理 | `GET /admin/export/tasks/meta` 返回 `code=200` |
| `databi` | **数据平台** `data.csdn.net`（`run_selection.py` 取数用） | 对话页 `…/chat` | 打开 `…/chat` **没被踢到 `/login`** 且**对话输入框在位** |

> ⚠ **两个站的登录态互相独立**：2026-09-29 是 `data.csdn.net` 过期，导致 `run_selection.py` 报
> 「对话页找不到输入框」，而广告后台同时完全正常——所以别拿 A 站的探针去看 B 站。
> `databi` 的探测走**另一个标签页**，不打扰你正在填的那个窗口。

窗口用**最大化**打开——固定视口（如 1680×1000）在比它小的屏幕上会把右侧挤出屏幕，
用户就点不到登录入口了（2026-09-16 踩过）。

## 判定口径与退出码

- 退出码：恢复 0 / 未恢复（超时或窗口被关）1。

## 边界

- **只读**：只发只读探测（GET 接口 / 打开对话页），不点页面上任何按钮、不下载、不创建。
- 它探的是**导出模块**的权限。如果哪天别的模块也出现"按模块失效"，
  把 `PROBE_PATH` 换成那个模块的只读接口即可。
