# 复盘会话格式

> **审批保护**：未经用户当次明确允许，不得修改本文件。
> **管什么**：到门槛后，AI 在复盘对话中必须如何展示结论、桶、文案改前/改后、问题和产物。
> **不管什么**：什么时候触发复盘 → [`workspace_review.md`](workspace_review.md)；文案怎么选和怎么改 → `../../ad_output/流程文档/`。
> **谁什么时候读**：定时任务创建复盘对话、AI 生成复盘草案、运营审阅复盘结果时。

## 首次回复

首次回复只给可审阅结果，不写读取过程、工具调用和历史叙述。

```markdown
【达标】
<曝光> 曝光 / <点击> 击 · 门槛 <门槛> · <结论>

### <活动> · <桶>（<曝光> 曝光 / <点击> 击 · 门槛 <门槛>）
本轮：<资源> 留 ｜ <资源> 下 → 下一轮 = N 条幸存 + M 个待处理位

1. <动作> · <槽位>（CTR，备注）
改前
标题：<逐字原文>

改后
标题：<逐字原文 /（不动）>
摘要：<逐字原文>

卡点：<为什么这样改，一行>

【问你】

【产物】
- <文件路径或“本轮无文件”>
```

## 强制规则

- 一个桶一段，段首固定使用 `### 活动 · 桶（读数）`。
- 每条文案独立成块，跨桶连续编号。
- “改前”必须逐字抄原文，不能概括、改写或只给摘要。
- “改后”标题、摘要必须齐全；标题没动写“（不动）”。
- 摘要小改必须展示原摘要、新摘要、重写方式、使用证据和字数。
- 补货文案必须展示编号、`角度 ID × 风格 · 文案 ID`、标题、摘要（带字数）和两个字段。
- 文案正文使用反引号。
- “本桶最高”只标在该桶 CTR 最高的文案上。
- 过程叙述只写报告文件，不进入对话。
- 存疑和边界说明最多各一行。
- 结尾必须给【问你】和【产物】；没有问题时写“无”。
- 用户确认前只给草案，不建 issue、不提交代码、不创建或修改 CSDN 后台对象。
