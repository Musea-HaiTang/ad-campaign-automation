# 执行层实测耗时

> **管什么**：当前执行层各脚本和关键流程最近一次有效实测，用来判断正常量级和异常明显超时。
> **不管什么**：流程规则、脚本参数或故障处理 → [`执行层全流程.md`](执行层全流程.md) 和对应脚本说明。
> **谁什么时候读**：改完脚本准备对比性能、排查某一步是否异常变慢时。

## 维护规则

- 每个脚本或流程只保留**最近一次有效实测**；再次测得新数据时直接覆盖对应行，不追加历史流水。
- 脚本或运行架构变化后，旧结果只能标成“待复测”，不能当作当前基线。
- 同一行必须写清日期、量级和口径；不同条件的结果不能混着比较。
- 本文件只记数和一句结论，不记实验过程、事故复盘或旧版本对比。

## 口径

- **脚本自报**：脚本打印的 `⏱ 总用时 X 秒`，通常不含公共浏览器首次启动。
- **墙钟**：整条命令实际耗时，包含浏览器启动、首屏和进程退出。
- 两种口径不能混用；同一行内统一口径。

## 使用方式

- 新数据符合同一条件时，直接替换对应行的日期和结果。
- 没有可比数据时，新增一行场景，不保留同一场景的历史版本。
- 实测显著超出本表量级时，先查日志和环境，不要用“以前也差不多”掩盖回退。
