# 日志、临时文件与浏览器缓存清理

> **管什么**：项目运行日志、临时文件、临时截图和浏览器可重建缓存的保留期限与清理入口。
> **不管什么**：数据库备份恢复见 [`数据库v2说明.md`](数据库v2说明.md)；业务活动和断点文件不在这里清理。
> **谁什么时候读**：定期维护磁盘、浏览器停止后处理缓存，或 profile 过大时。

## 日常清理

```powershell
.venv\Scripts\python.exe automation/scripts/cleanup.py
```

默认规则：

- `activities/{活动}/日志/` 下的 `.log` 保留 7 天；
- `automation/_tmp/` 下的普通临时文件清理 1 天前的；
- 活动日志和 `_tmp` 下的临时截图最多保留 30 天；
- 断点账本、活动配置、物料、数据库、数据库备份不清理。

先预览：

```powershell
.venv\Scripts\python.exe automation/scripts/cleanup.py --dry-run
```

## 浏览器缓存

公共浏览器正常停止时，最多每 7 天自动检查一次 profile。可重建缓存超过
200 MB，或距上次清理超过 7 天时，自动清理安全缓存。

也可以先停止浏览器再手动清理：

```powershell
.venv\Scripts\python.exe automation/scripts/browser_broker.py --stop
.venv\Scripts\python.exe automation/scripts/cleanup.py --browser-profile
```

浏览器仍在运行时，手动清理命令会拒绝执行。

默认安全缓存包括 HTTP Cache、Code Cache、GPU/着色器缓存、Crashpad 和组件 CRX 缓存。
以下内容始终保留：

- `Default/Network/Cookies`
- `Local State`
- `Default/Preferences`
- `Default/Extensions`
- `Default/Service Worker/CacheStorage` 与 `ScriptCache`

Service Worker 缓存保留是因为数据平台登录可能依赖其中的站点状态，不能按普通 HTTP
缓存处理。

profile 总大小超过 1 GB 时不会自动清理。运营确认后可以执行深度清理：

```powershell
.venv\Scripts\python.exe automation/scripts/cleanup.py --browser-profile --deep
```

`--deep` 只额外清理可重新下载的 Edge 组件、模型和跳转图标缓存；不会删除 Cookie、
登录态、偏好设置或扩展配置。
