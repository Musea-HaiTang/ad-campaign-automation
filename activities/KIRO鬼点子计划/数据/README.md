- 圈选数据来自**数据平台**（`data.csdn.net` 对话式取数），过滤口径写死在提示词里：`status = 1` + `last_30_days_pv > 1` + 六字段 `multiMatchAny`；
  导出的是**博文**（article_id / title / article_url / last_30_days_pv），人是从博文倒推的。
