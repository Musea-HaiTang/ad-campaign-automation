# 广告流程术语真源

> **管什么**：广告全流程中的专有名词、唯一定义和同义关系。
> **不管什么**：文案风格术语 → `../文案风格/术语/README.md`；活动事实 → 各活动的 `活动细则.md`。
> **谁什么时候读**：建想法池、选角度、写流程、解释或修正专有名词时。

## 真源规则

1. 一个流程术语只在本文件定义一次；其他流程文档只引用名称，不复制定义。
2. 同一术语在不同文档中冲突时，以本文件为准，并回头修正引用处。
3. 新增流程术语前先在这里定名、定边界；没有登记的名称不进入流程。
4. 文案风格术语继续以 `../文案风格/术语/README.md` 为唯一索引，不在本文件重复定义。

## 选角度

| 术语 | 定义 |
|---|---|
| 桶 | 一个可独立投放和判定的单元：单页活动按目标人群拆，多产品活动按顶格产品拆。 |
| 钩子 | 能让目标人群停下来并点进来的那句话；产品参数、文档或活动规则本身只是素材，不能直接算钩子。 |
| 卖点 | **产品有什么**：有官方事实支撑的能力、参数、收益或资源；卖点本身是素材，不能直接等同于角度。 |
| 读者证据卡 | 选角度前的输入材料，记录真实关键词、典型任务、用户现有做法、核心困难、可用事实与历史信号。 |
| 读者问题 | 角度想回答的、会影响目标读者行动的具体问题。 |
| 角度 | 为某个目标人群选定并用于测试的读者问题，以 `角度 ID` 管理。核心区别是：**卖点是产品有什么；角度是这群人为什么现在要在意它。** |
| 角度句 | 按统一句式表达一个读者问题的标准句子；建池时先生成 8～10 个。 |
| 主角度 | 当前批进入后续文案流程的角度。 |
| 备选角度 | 完整且合格，但尚未进入当前批的角度；不固定数量。 |
| 角度复核 | 当前批主角度交给后续写文案流程前的最后检查；只查重复、行动后果、证据和明显缺口，不看投放数据。 |

## 想法池与验证

| 术语 | 定义 |
|---|---|
| 任务组 | 后台最上层的投放容器。 |
| 客群 | 由关键词圈选得到的一组目标用户。 |
| 资源 | 一条正式广告素材，包含标题和两行描述。 |
| 任务工单 | 把客群和 1～3 个资源绑定起来、用于一个桶独立投放和判定的后台对象；1 资源走 AB测试=否。 |
| 钩子闸门 | 单页活动决定候选人群能否成为桶的入口检查；每个候选人群需给出 2 个不同钩子。多产品活动不执行本闸门。 |
| 想法池 | 按「角度 → 文案」两层维护的待验证清单；只放还没上过的角度与文案，具体状态和库存规则见 `想法池与1000曝光复盘流程.md`。 |
| 资源位 | 某一批里承载一条正式文案的后台资源位置；默认一个资源位对应一个不同角度。 |
| 验证位 | 一个角度内部 `首测` / `补验` 两种文案角色。 |
| 首测 | 一个角度的第一条正式文案。 |
| 补验 | 与首测属于同一角度、但写法不同的第二条正式文案。 |
| 备选文案 | 额外保留但未占 `首测` / `补验` 验证位的文案。 |
| 角度死亡 | 首测和补验都达到判定门槛且均为 `0` 击。 |
| 小改 | 复盘已决定小改后，角度、卖点、风格和事实不变，标题默认不动，只重写摘要；执行方法见 `小改流程.md`。 |

## 文案分类

| 术语 | 定义 |
|---|---|
| 文案类型 | 本项目当前启用的一种测试标签，用于区分广告呈现方式；当前只有 `伪装成推荐博文` 和 `纯营销类` 两个值，不构成广告文案类型的穷尽分类。 |
| 写作形态 | 教程、问答、案例、清单、公告、对比、故事等具体写法；默认归入某个文案类型之下，不自动成为新的项目类型。 |
