# 广告记忆与经验目录

> **管什么**：广告吸引力规则、待验证候选的文件边界与发布规则。
> **不管什么**：投放事实和逐条数据 → 数据库 `activities/_db/投放数据.db`；流程与写法 → `../流程文档/`、`../文案风格/`。
> **谁什么时候读**：写文案前、复盘后准备沉淀经验、准备发布项目时。

## 文件边界

| 文件 | 作用 | 发布 |
|---|---|---|
| `MEMORY.md` | 跨场景吸引力原则和真实踩坑 | 是 |
| `暂缓经验-产品类.md` / `暂缓经验-大赛类.md` | 当前项目待验证候选 | 否 |
| `暂缓经验-*-历史.md` | 当前项目历史证据 | 否 |
| `模板/暂缓经验模板.md` | 新项目登记待验证候选 | 是 |

## 新项目怎么用

1. 先读 `MEMORY.md`。
2. 逐条指标、批次、文案快照和复盘状态统一查询 SQLite。
3. 需要总结经验时，直接按数据库记录复核；经验成立并获用户确认后写入 `MEMORY.md`。
4. 有未验证候选时，复制 `模板/暂缓经验模板.md`。
