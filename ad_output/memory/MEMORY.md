# 广告吸引力经验

> **管什么**：跨文案场景都要记住的用户偏好、注意力原则和真实踩坑。
> **不管什么**：选角度、想法池、文案类型、风格术语、自审和复盘流程，均回到对应真源。
> **谁什么时候读**：分人群、选角度和写文案前。

本文件只收用户明确确认、能跨活动复用的判断；新增或修改仍须用户同意。

## 1. 留住注意力

- **标题必须自己就是钩子**：用户通常只看标题，标题不能依赖摘要或品牌名补足吸引力。
- **先让人停下来，再要求他点击**：扫读位只有几秒。形式、具体词、数字、冲突或场景都可以负责“停下来”；随后必须让目标读者知道“点进去能得到什么或避免什么”。
- **始终从目标人群视角判断**：文案对写的人再有道理，只要目标读者不关心、不觉得与自己有关，就不算有吸引力。

## 2. 真实踩坑

- **数字和英文堆叠会劝退**：连续分数、多个数字并列、基准名和框架名成串出现，会增加阅读成本。只保留目标人群本来熟悉的一个专名。
- **官方材料是证据，不是文案**：模型卡、参数表、基准表和功能清单用于核对事实，不能整段搬成广告语。
- **不替用户发明活动特例**：产品形态、许可、敏感题材、禁用说法等特例，只按用户明确给出的内容写；缺信息就问。
