# 文案自审

> **审批要求**：未经用户当次明确允许，不得新增或修改本文件。
> **何时走**：写文案 → 自审 → 才出物料 / 进 YAML。
> **谁审**：AI 自己审、自己定稿；用户只在特别喜欢或不认可时介入。
> **定稿写清**：`目标人群 ｜ 本轮角度 ｜ 吸睛点 ｜ 点击理由 ｜ 卖点判定 ｜ 出处`。
> **风格文案追加**：`原句核心 ｜ 产品承接 ｜ 诗词在句中的作用`。
> `卖点判定 = 省步骤 / 省成本 / 别人做不到 / 独有资源 / 突出优势·场景收益`；入池写进现有的 `差异类型 · 出处`。

## 审核

1. **人群和角度**
   - 文案是否写给预先确定的人群；
   - 是否表达本轮角度，没有退化成普通产品介绍。

2. **达：整句语义**
   - 主语、谓语、宾语是否完整；
   - “它、这次、这、那”等指代是否明确；
   - 动宾搭配是否正常；
   - 因果、转折和时间关系是否成立；
   - 标点和断句是否对应；
   - 诗词或来源表达是否进入整句语法，不是悬空引用；
   - 原句核心和产品承接是否属于同一语义关系；
   - 用普通白话复述后，意思是否仍然完整；
   - 连续朗读是否像正常人会说的话。

3. **雅：风格融入**
   - 只能标：对仗 / 化用 / 借鉴诗词 / 常规；
   - 标了风格就按 [`术语/README.md`](术语/README.md) 找到对应真源核验；
   - 借鉴诗词和化用写清 `原句核心 ｜ 产品承接 ｜ 诗词在句中的作用`；
   - 风格是否让表达更准确、凝练、有画面或节奏；
   - 风格是否降低清晰度、增加解释成本或只剩装饰；
   - 化用和借鉴诗词不得默认固定在句首；多条候选要按语义分散到句首、句中或句尾，不能全部套“来源句在前 + 产品句在后”；
   - 借鉴诗词的前后句字数相同只是自然贴合时的节奏增强，不是硬要求；为了凑等长而削掉产品信息或写得不顺，直接改回自然长短；
   - 对仗另核字数、结构、词性，并确认去除形式后事实和读者收益仍成立；**4+4 / 5+5 不合格**，6+6 / 7+7 正常使用；
   - 风格没有改善表达，或者无法自然融入时，改常规或换句；
   - 常规只作基线；首测阶段不限制常规条数，风格差异通过补验验证。

4. **吸睛点和点击理由**
   - 只看标题：什么词、句、数字、冲突、场景或形式感能让人停住；
   - 分别写清吸睛点和点击理由；
   - 诗词、对仗等只能负责吸睛；活动名、品牌名、产品功能和风格本身都不算点击理由；
   - 只有形式感，没有读者收益或损失，不算过关。

5. **卖点**
   - 先做竞品替换测试；
   - 换成同行后不成立：写相对优势，标省步骤 / 省成本 / 别人做不到 / 独有资源；
   - 换成同行后仍成立，或没有竞品证据：不硬造差异，改选本产品的突出优势；
   - 突出优势必须有证据，并落到目标人群的具体任务、场景或结果；
   - 只选一个最相关、最有说服力的优势，不堆功能清单；
   - 不写“只有 / 独家 / 唯一”，除非官方原文；
   - 说不清为什么选这项优势，或说不清读者能得到什么 → 换文案或换角度。

6. **信：证据**
   - 每句话都能对应活动细则、官方页面或后台实测；
   - 诗词原句、作者、出处准确；
   - 只用核到的数字和能力；
   - “最 / 第一 / 彻底 / 唯一”等绝对化表达，除非官方原文，否则不用。

7. **看懂、内容类型和硬扫**
   - 标题 3 秒内能看出“这跟我有什么关系”；
   - 不需要心算、切换语言或先理解典故；
   - 英文专名最多留一个目标读者本来就认识的；
   - 伪装博文型：不能被一眼当成硬广；
   - 纯营销型：必须有一个具体好处；
   - 检查空话、能力清单堆砌、视角错位、场景过窄、没核到的数字、拉踩同行和敏感词；
   - 好处句放摘要第一句，截止日 / 活动说明往后放；
   - 同一角度改 2 轮仍不过 → 换下一条文案。

## 摘要小改

- 小改是否触发由复盘流程决定；一旦决定小改，就不再读取点击数和 CTR 决定怎么改。
- 标题默认保持原文不变；摘要可以整句重写，不要求保留原句结构。
- 角度、点击理由、文案风格、事实和证据来源不变。
- 只输出一条默认新摘要，不再生成四选一，也不把换风格混入小改。
- 新摘要必须产生实质变化，不能只改标点、时间词或公文式措辞。
- 生成方法、事实卡和输出格式只看 `../流程文档/小改流程.md`。
- 本文件的审核关是生成后的最终闸门，不拿审核清单代替小改的起稿方法。

## 句子与展示

- 标题和摘要逐句检查：主谓完整、前后关系明确、标点对应、主语不中途换人；
- 风格必须和产品连续成句，不能靠机械追加解释掩盖语义断裂；
- 摘要写全动作、结果、关键数字或截止日，≤ 45 字；
- 标题无硬上限，但不能“长而空”；

## 边界

- 文案唯一来源是想法池；
- 标题自己就要构成吸引，不依赖摘要或品牌名补足；
- 官方材料、参数表和功能清单只作为事实证据，不整段搬成文案；
- 产品形态、许可、敏感题材和禁用说法等活动特例只按用户明确给出的内容写；
- 不为凑风格标签牺牲正常表达；
- 自审只保证不犯低级错误，哪条有效由点击数据判断。
