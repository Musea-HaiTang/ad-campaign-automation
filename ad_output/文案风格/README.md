# 文案风格

> **管什么**：写文案时的入口、阅读顺序、三种风格的选择规则、混批方式与目录索引。
> **不管什么**：文案风格术语定义 → `术语/README.md`；流程术语 → `../流程文档/术语真源.md`；选角度 → `../流程文档/选角度流程.md`；文案审核 → `文案自审.md`。
> **谁什么时候读**：建想法池、补货、写文案和审核风格标签前。

## 写作顺序

1. 按 `../流程文档/选角度流程.md` 定角度；
2. 按 `两种文案类型.md` 定当前广告呈现类型；
3. 从本文件选择风格，再到 `术语/` 打开对应真源核对；
4. 写正式文案；
5. 按 `文案自审.md` 完成审核；定稿写清目标人群、本轮角度、吸睛点、点击理由、卖点判定和出处。

## 当前三种风格

1. **借鉴诗词**：保留真实诗词片段，把它融入完整语句，让产品承接与原句语义一致，并提升语言表达。
2. **化用**：借用明确来源的诗句、古文、名人名言、歇后语、俗语或谚语，把原句的核心意思改写成产品文案的一部分。
3. **对仗**：字数、结构、词性严格对应，同时承载具体事实；**4+4 / 5+5 不再使用，6+6 / 7+7 正常使用**。

选择顺序：**借鉴诗词 ＞ 化用 ＞ 对仗**。

文案风格术语的定义和判断方法只在 `术语/` 对应文件中维护；选角度等流程术语以 `../流程文档/术语真源.md` 为准。

## 验证位与批次规则

- 每个角度固定两个验证位：
  - `首测`：当前最强钩子，不限风格；
  - `补验`：必须是合格风格文案，与首测属于同一角度但写法不同。
- 首测已经是风格时，补验优先换另一种风格。
- 额外满意的文案标 `备选`；备选不占两个验证位，也不自动进下一批。
- 一批仍取三个不同角度各一条；**首测不强制混风格**，只按角度强度选。常规首测可以同时出现多条，风格测试放到对应角度的补验里。只有用户明确要求比较风格时，才在同一角度放多个风格版本。
- 一条文案只使用一种风格；**常规不是风格**，只作对照基线。
- 三种风格都必须先通过整句语义和信达雅检查。某种风格无法自然成立时，明确标 `风格不成立` 并说明原因，不硬凑。
- 角度或卖点不成立时，不靠风格补救。
- 标题先负责让人停住；如果整句需要读者猜典故、比喻或产品含义，就改写或换角度，不靠机械追加解释。

## 后端槽位口径

- 1 桶 = 1 工单 = 3 个资源槽位（后台固定叫法：`对照 34 / 实验1 33 / 实验2 33`）。
- 文案写法上的三条是并列角度，不是“对照 + 两条陪跑”；后台槽位名不等于文案分组。
