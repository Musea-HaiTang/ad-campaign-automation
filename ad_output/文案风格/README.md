# 文案风格（CSDN 页面类广告）

> ⛔ **这个目录只是参考资料，不是必须遵守的规范**（用户 2026-09-28 定）。
> **「文案风格」这个概念已取消**：不再有"写文案前先选一种风格"，也没有「默认风格」了。
> **别把本目录任何一份文件当模板套。**
> 流程位置见 `../流程文档/CSDN广告投放自动化流程.md` §6。

**所有写法共有的结构**（用户 2026-09-22 定）：每桶 3 条 = 同人群的**三个角度（= 三种钩子）**，
**一条文案对应一个**，**没有对照组**（三条都得有钩子，没有"陪跑"那条）。

## 这个目录里有什么

| 文件 | 讲什么 |
|---|---|
| [`用户痛点版.md`](用户痛点版.md) | **参考**：一套你认可过的写法（标题「想让 X，就 Y」+ 描述两句）。句式规则是 AI 提炼的、**不强制**。 |
| [`两种文案类型.md`](两种文案类型.md) | ① 伪装成推荐博文 / ② 纯营销类——**分类本身是你 2026-09-24 定的** |
| [`文案自审.md`](文案自审.md) | **必过流程**：AI 自己审、交付时展示过程 |

## 后台结构（与写法无关）

- 1 桶 = 1 工单 = 3 个资源槽位（`对照 34 / 实验1 33 / 实验2 33`），资源名由 `automation/scripts/naming.py` 生成。
- 「没有对照组」说的是写法：三条都是角度、谁都不陪跑；资源名里的「对照 / 实验1」是后台槽位的固定叫法，不是文案口径。
