# 当前两种广告呈现类型（伪装博文型 / 纯营销类）

> 用户 2026-09-24 定的分类：「我们的文案其实大致可以分为 2 种类型，一种是伪装成下面的类似推荐博文，一种是纯营销类博文。」
> 本文维护**本项目当前启用的两种广告呈现标签**：伪装博文型 / 纯营销类；逐条自审见 [`文案自审.md`](文案自审.md)。
>
> ⛔ **边界**：这两个标签描述广告的呈现方式，**不是广告文案类型的穷尽分类**。教程、问答、案例、清单、公告、对比、故事等属于具体写作形态，默认归入上述两种呈现类型之下，不自动成为新的项目类型。

## 对比

| | **① 伪装成推荐博文型** | **② 纯营销类** |
|---|---|---|
| 一句话 | 让广告读起来像推荐位里的一篇技术帖 | 直接讲产品 / 活动的好处 |
| 读者第一反应 | 「这是一篇文章」 | 「这是广告，但说的东西跟我有关」 |
| 关键词选谁 | 读者关心的**主题词**（短视频、音视频、图片、成本） | 产品的**动作 / 能力 / 激励**（装、Skill、额度、大赛） |
| 风险 | 产品词说太多会露馅；**不许编造体验和数字** | 广告腔太重，被一眼划过 |

## 怎么用（2026-09-24 起）

- **不再要求"同一批里两种都要有"**（**2026-10-09 用户定**：大赛 / 活动宣传这类，**②型（营销类）反而直接一点、
  效果可能更好**，"后续复盘没必要遵循同批两种都要写"）。写文案时按**这条文案怎么说最清楚**选类型即可，
  **不用为了凑齐两种类型去补写 ①型**。
  （旧的"补齐①型好做同批对比"已经用过几轮：①型在 KIRO C 三批 6,926 曝光 0 击、火山 C 两轮 0 击——要再验类型，
  就**整批都用同一种**，别一条一条混着试。逐条数据直接查数据库。）
- 每条文案**在物料和数据库里都要标类型**（①②），复盘按类型分组看点击。
- 类型是叠在"角度"上的第二个维度：同一批三条仍然是**三个角度**，只是写法类型可以不同。

确需新增类型时，先写清它与“角度 / 写作形态 / 风格”的区别，并经过用户确认后再进入测试；不能因为标题或句式看起来不同，就自建第三种类型。
