# 两种文案类型（伪装博文型 / 纯营销类）

> 用户 2026-09-24 定的分类：「我们的文案其实大致可以分为 2 种类型，一种是伪装成下面的类似推荐博文，一种是纯营销类博文。」
> 本文只讲**有哪两种、怎么分辨、各怎么写**；逐条自审见 [`文案自审.md`](文案自审.md)。

## 对比

| | **① 伪装成推荐博文型** | **② 纯营销类** |
|---|---|---|
| 一句话 | 让广告读起来像推荐位里的一篇技术帖 | 直接讲产品 / 活动的好处 |
| 读者第一反应 | 「这是一篇文章」 | 「这是广告，但说的东西跟我有关」 |
| 关键词选谁 | 读者关心的**主题词**（短视频、音视频、图片、成本） | 产品的**动作 / 能力 / 激励**（装、Skill、额度、大赛） |
| 风险 | 产品词说太多会露馅；**不许编造体验和数字** | 广告腔太重，被一眼划过 |

> **飘红不在类型规则里**（用户 2026-09-28 定：「飘红是文案的一部分，你自己决定有没有必要」）：
> 飘不飘、飘哪个词，写这条文案时自己定。
> 用户的补充（2026-09-28）：**①型带一个关键词飘红可能会好一点**——推荐位里那些博文基本都有飘红，
> 飘一个主题词更像其中一员；**②型没这个问题**，飘红只用来强调。具体每条自己判断。

## 怎么用（2026-09-24 起）

- **同一批里两种都要有**：现在在跑的存量文案基本都是②型，所以新一轮补齐①型——同批 / 同人群 / 同位置，
  数据上直接可比（这是"类型到底有没有用"的唯一判据）。
- 每条文案**在物料和台账里都要标类型**（①②），复盘按类型分组看点击。
- 类型是叠在"角度"上的第二个维度：同一批三条仍然是**三个角度**，只是写法类型可以不同。
