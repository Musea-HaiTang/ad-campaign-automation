# 文案风格术语索引

> **管什么**：文案写作相关术语的唯一索引；每个术语只维护一份定义。
> **不管什么**：三种风格的使用规则 → `../README.md`；文案审核流程 → `../文案自审.md`。
> **谁什么时候读**：写文案、补池子、审核风格标签或发现术语混用时。

## 真源规则

1. **一个术语一个文件**：定义、边界、判断标准和示例只写在对应文件里。
2. **其他文档只引用**：风格总览、自审、流程和想法池只使用术语名并链接到本目录，不复制定义。
3. **冲突裁决**：同一术语在各处出现不一致时，以本目录对应文件为准，并回头修正引用处。
4. **新术语先建文件**：新增术语前先确定文件归属；没有真源文件，不进入风格标签或审核判据。
